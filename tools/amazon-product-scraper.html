Amazon Product Scraper

Prices, BSR, Sales & Price Tracker

Scrape Amazon products without login: price, Best Sellers Rank, bought in past month, seller, stock, specs, variants, images and review summary from searches, Best Sellers, ASINs or links in 16 stores. Local delivery postcode and price tracking. For sellers, price monitoring and market research.

Example input

Paste this into the Actor's JSON input, or send it with the API call below.

{
  "searchTerms": [
    "wireless earbuds"
  ],
  "marketplace": "com",
  "maxResultsPerSearch": 10,
  "proxyConfiguration": {
    "useApifyProxy": true
  }
}

Run it from code

Use your Apify API token. The call waits for the run and returns the rows.

curl -X POST "https://api.apify.com/v2/acts/panix~amazon-product-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"searchTerms":["wireless earbuds"],"marketplace":"com","maxResultsPerSearch":10,"proxyConfiguration":{"useApifyProxy":true}}'
from apify_client import ApifyClient

client = ApifyClient("APIFY_TOKEN")
run = client.actor("panix/amazon-product-scraper").call(run_input={
    "searchTerms": [
        "wireless earbuds"
    ],
    "marketplace": "com",
    "maxResultsPerSearch": 10,
    "proxyConfiguration": {
        "useApifyProxy": True
    }
})

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: process.env.APIFY_TOKEN });
const run = await client.actor('panix/amazon-product-scraper').call({
  "searchTerms": [
    "wireless earbuds"
  ],
  "marketplace": "com",
  "maxResultsPerSearch": 10,
  "proxyConfiguration": {
    "useApifyProxy": true
  }
});

const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
