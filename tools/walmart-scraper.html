Walmart Scraper

Products, Prices, Reviews & Price Tracker

Scrape Walmart products and reviews without login: price, was-price, seller, stock, UPC, specs, every variant with its price, rating breakdown, store aisle, pickup and delivery. From searches, categories, deals, item IDs or links. Price tracking for sellers, brands and price monitoring.

Example input

Paste this into the Actor's JSON input, or send it with the API call below.

{
  "searchTerms": [
    "air fryer"
  ],
  "maxResultsPerSearch": 10,
  "proxyConfiguration": {
    "useApifyProxy": true
  }
}

Output fields

Every row has the same fields. Export as JSON, CSV, Excel or XML.

  • mainImage
  • title
  • brand
  • price
  • wasPrice
  • rating
  • reviewsCount
  • sellerName
  • inStock
  • boughtRecently
  • url

Run it from code

Use your Apify API token. The call waits for the run and returns the rows.

curl -X POST "https://api.apify.com/v2/acts/panix~walmart-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"searchTerms":["air fryer"],"maxResultsPerSearch":10,"proxyConfiguration":{"useApifyProxy":true}}'
from apify_client import ApifyClient

client = ApifyClient("APIFY_TOKEN")
run = client.actor("panix/walmart-scraper").call(run_input={
    "searchTerms": [
        "air fryer"
    ],
    "maxResultsPerSearch": 10,
    "proxyConfiguration": {
        "useApifyProxy": True
    }
})

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: process.env.APIFY_TOKEN });
const run = await client.actor('panix/walmart-scraper').call({
  "searchTerms": [
    "air fryer"
  ],
  "maxResultsPerSearch": 10,
  "proxyConfiguration": {
    "useApifyProxy": true
  }
});

const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
