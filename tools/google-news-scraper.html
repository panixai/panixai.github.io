Google News Scraper & Monitor

Real Links, Text, New Only

Get Google News articles by keyword, topic or place with the real publisher link, source, date and related coverage. Add article text, or get only new articles since your last run. Schedule it for news alerts and AI agents. No login.

Example input

Paste this into the Actor's JSON input, or send it with the API call below.

{
  "searchQueries": [
    "artificial intelligence"
  ],
  "timeframe": "1d",
  "maxResultsPerSearch": 20,
  "proxyConfiguration": {
    "useApifyProxy": true
  }
}

Output fields

Every row has the same fields. Export as JSON, CSV, Excel or XML.

  • title
  • source
  • publishedAt
  • url
  • search
  • country
  • relatedCount

Run it from code

Use your Apify API token. The call waits for the run and returns the rows.

curl -X POST "https://api.apify.com/v2/acts/panix~google-news-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"searchQueries":["artificial intelligence"],"timeframe":"1d","maxResultsPerSearch":20,"proxyConfiguration":{"useApifyProxy":true}}'
from apify_client import ApifyClient

client = ApifyClient("APIFY_TOKEN")
run = client.actor("panix/google-news-scraper").call(run_input={
    "searchQueries": [
        "artificial intelligence"
    ],
    "timeframe": "1d",
    "maxResultsPerSearch": 20,
    "proxyConfiguration": {
        "useApifyProxy": True
    }
})

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: process.env.APIFY_TOKEN });
const run = await client.actor('panix/google-news-scraper').call({
  "searchQueries": [
    "artificial intelligence"
  ],
  "timeframe": "1d",
  "maxResultsPerSearch": 20,
  "proxyConfiguration": {
    "useApifyProxy": true
  }
});

const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
