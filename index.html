One HTTP call per tool

Send the input, get the rows back. Works from any language, n8n, Make, Zapier, and AI agents through Apify's MCP server.

  • Synchronous endpoint returns rows directly
  • Same field names on every run
  • Webhooks when a scheduled run finishes
curl -X POST "https://api.apify.com/v2/acts/panix~google-news-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"searchQueries":["artificial intelligence"],"timeframe":"1d","maxResultsPerSearch":20,"proxyConfiguration":{"useApifyProxy":true}}'
from apify_client import ApifyClient

client = ApifyClient("APIFY_TOKEN")

        "useApifyProxy": True

for item in client.dataset(run["defaultDatasetId"]).iterate_items():

Questions

How do I try a tool?

Open the tool and press Run on Apify. Apify's free plan includes monthly credit, which is enough to test any of these tools on real data.

How much does it cost?

You pay per result, from $0.60 per 1,000. Each tool page lists every price. Searches that find nothing cost nothing, and you can cap any run with a spend limit.

Can I call these from my own code or AI agent?

Yes. Every tool is an HTTP endpoint: send JSON input, get rows back as JSON, CSV or Excel. Each tool page has ready cURL, Python and JavaScript calls. The tools also work through Apify's MCP server for AI agents.

Do I need a login or cookies?

No. The tools read public pages only and never solve captchas.

Can I get only new results every day?

Many tools have an only-new mode. Schedule the run on Apify and you get only the items that weren't there last time, sent to Sheets, Slack, a webhook or email.

What if a website changes?

The tools run against their live sources on a schedule. When a site changes, the tool is fixed and the change goes into its changelog on Apify.

Need a source that isn't here?

I build custom scrapers and daily data feeds. Send the site, a few example pages and where the data should go.
